# 教案：《小蝌蚪找妈妈》

## 一、基本信息区

- **课题**：小蝌蚪找妈妈
- **年级**：二年级（上册）
- **课时**：2课时（本教案按第一课时精读设计，第二课时巩固与拓展）
- **教材版本**：统编版义务教育教科书 语文 二年级上册 第一单元

## 二、教学目标（基于核心素养四维度）

### 文化自信
1. 感受小蝌蚪在成长过程中展现的生命力量，体会大自然的神奇与美好。
2. 理解课文中"耐心寻找、不轻言放弃"所蕴含的优秀传统文化价值（恒心、坚持）。
3. 增强对自然生命的热爱与敬畏，萌发保护有益动物（青蛙）的意识。

### 语言运用
1. 认识"塘、脑、袋、灰、哇、教、捕、迎、阿、姨、宽、龟、顶、披、鼓、碧、蹲、露、裳"等 15 个生字，会写"两、就、哪、宽、顶、睛、肚、皮、孩、跳"10 个生字。
2. 理解"游来游去、碧绿、雪白、快活"等词语的意思，能在具体语境中正确运用。
3. 正确、流利、有感情地朗读课文，读好小蝌蚪和动物们的对话语气。
4. 学习"游来游去"式（A来A去）词语和"大大的、长长的"式叠词的表达效果。

### 思维能力
1. 通过观察插图、对比小蝌蚪身体的变化，理清蝌蚪变青蛙的成长顺序。
2. 梳理小蝌蚪找妈妈的经过（遇鲤鱼→遇乌龟→遇青蛙），概括课文主要内容。
3. 边读边想象画面，体会"大大的脑袋、长长的尾巴、碧绿的衣裳、雪白的肚皮"等描写。
4. 联系生活实际，思考"遇到困难如何坚持、如何获取准确信息"的问题。

### 审美创造
1. 感受课文生动形象的语言美，体会用词的准确性（"蹲、披、露、鼓、甩"等动词）。
2. 鉴赏课文中拟人化手法和对话描写的艺术特色。
3. 能够用生动的语言描述小动物的外形和动作。
4. 在理解的基础上，创编一种小动物成长的小故事。

---

## 三、教学重难点

### 教学重点
1. 认识生字，会写生字；理解重点词语。
2. 理解小蝌蚪变成青蛙的生长过程，理清变化顺序。
3. 正确、流利、有感情地朗读课文。

### 教学难点
1. 体会小蝌蚪在寻找妈妈过程中的心情变化（从着急到高兴）。
2. 学习并运用"A来A去""大大的"等叠词，进行表达迁移。
3. 把握对话中的不同语气，读好不同角色的语言。

## 四、教学准备

### 教师准备
1. 多媒体课件（含小蝌蚪生长过程动画/图片）。
2. 生字卡片、词语卡片。
3. 课文情景配图（蝌蚪→长出后腿→长出前腿→尾巴变短→青蛙）。

### 学生准备
1. 预习课文，圈出生字新词，借助拼音读准字音。
2. 观察或查阅蝌蚪、青蛙的图片、视频，了解其外形。

## 五、教学过程

### （一）导入新课（3分钟）
**谜语导入**："大脑袋，长尾巴，游来游去像逗号，长大变成绿青蛙。"猜猜这是什么动物？
学生猜出是蝌蚪。
师：对啦！就是可爱的小蝌蚪。可是小蝌蚪一出生就没见过妈妈，它们要去找妈妈。今天我们学习一篇有趣的童话——《小蝌蚪找妈妈》。（板书课题，齐读课题）

### （二）初读课文（6分钟）
1. 自由朗读课文，借助拼音读准字音，难读的句子多读几遍。
2. 同桌互读，互相纠正字音；圈出不懂的词语。
3. 检查生字：出示生字卡片，开火车认读"塘、脑、袋、灰……"。
4. 整体感知：课文主要讲了一件什么事？（小蝌蚪找妈妈，最后变成了青蛙。）

### （三）精读课文（18分钟）
1. **学习第1自然段**
   - 指名读，想象小蝌蚪的样子。
   - 品词："大大的脑袋，黑灰色的身子，甩着长长的尾巴，快活地游来游去。"
   - 比较"甩"与"摇"，体会小蝌蚪的活泼可爱。
2. **学习第2自然段（遇鲤鱼阿姨）**
   - 小蝌蚪发生了什么变化？（长出了两条后腿）
   - 分角色朗读对话，读好"鲤鱼阿姨，我们的妈妈在哪里？"的急切，"你们的妈妈四条腿，宽嘴巴"的亲切。
   - 提炼妈妈特征①：四条腿、宽嘴巴。
3. **学习第3自然段（遇乌龟）**
   - 又发生了什么变化？（长出了两条前腿）
   - 乌龟为什么不是妈妈？（乌龟也四条腿，但头顶没有大眼睛、没有绿衣裳）
   - 提炼妈妈特征②：头顶两只大眼睛、披绿衣裳。
4. **学习第4—5自然段（遇青蛙）**
   - 观察插图：青蛙什么样？（蹲在荷叶上，披碧绿的衣裳，露雪白的肚皮，鼓着大眼睛）
   - 品动词："蹲、披、露、鼓"，体会作者用词的准确生动。
   - 小蝌蚪最后怎样了？（尾巴变短→不见，长成青蛙，跳上荷叶）
5. **总结生长顺序**：大脑袋长尾巴 → 长后腿 → 长前腿 → 尾巴变短 → 尾巴不见（青蛙）。

### （四）拓展延伸（6分钟）
1. 观看小蝌蚪生长过程短视频，巩固变化顺序。
2. 联系生活：你还知道哪些动物的生长变化？（蚕、毛毛虫变蝴蝶、小鸡出壳……）
3. 讨论：小蝌蚪为什么能找到妈妈？（不放弃 + 每次都记下了妈妈的特征）

### （五）课堂小结（2分钟）
今天我们知道了小蝌蚪变成青蛙的过程，还认识了 15 个生字。小蝌蚪不怕困难、耐心寻找，最后终于和妈妈团聚。我们也要学习这种坚持的精神。

## 七、作业布置（分层）

### 基础作业
1. 抄写会写生字（两、就、哪、宽、顶、睛、肚、皮、孩、跳），每个 3 遍，并各组一个词。
2. 朗读课文 3 遍，读准字音，读出对话语气。

### 提高作业
1. 用"游来游去"写一句话；照样子再说两个"A来A去"的词语。
2. 看着板书，把小蝌蚪找妈妈的故事讲给爸爸妈妈听。

### 实践作业
观察身边的一种小动物（或养蚕、种豆），用图画或几句话记录它的样子和变化，下节课分享。

## 八、教学反思（课前预设，供课后填写）

本课教学目标基本能达成：学生通过谜语导入兴趣浓厚，借助插图和动画直观理解了蝌蚪的生长变化；"蹲、披、露、鼓"等动词的品读是亮点。

**需注意：**
- 二年级学生易把"追上去/迎上去"混淆，下次可加动作演示区分。
- 部分学生"A来A去"仿说较困难，需多给范例支架。
- "披"与"穿"的区别可结合生活再强化。
- 朗读对话时，小蝌蚪"急切—高兴"的语气变化需重点指导。
