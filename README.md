# 小学语文备课八件套（chinese-teaching-resources）

> **一键生成小学语文课文全套教学资源的 WorkBuddy 技能**

## 功能

针对任意小学语文课文，自动生成以下 **8 件套** 教学资源：

| # | 资源类型 | 说明 |
|---|---------|------|
| 1 | **教案** | 标准八部分结构，基于核心素养四维度目标 |
| 2 | **讲课稿** | 五环节口语化脚本，含互动提问与朗读指导 |
| 3 | **导学案** | 学习目标 / 预习 / 自主探究 / 合作探究 / 当堂检测 |
| 4 | **预习播客稿** | 课前音频播客脚本（背景 / 作者 / 生字预习） |
| 5 | **分层习题** | 基础(5) + 提高(5) + 拓展(3)，附参考答案 |
| 6 | **PPT 大纲** | 15 页幻灯片大纲，可直接照做 |
| 7 | **交互式学习网页** | 自包含单文件 HTML，双击即用，含生字卡/练习题/重点段落 |
| 8 | **课文配图** | 内联 SVG 配图嵌入交互网页 |

## 适用范围

- 统编版小学语文一～六年级全册课文
- 支持核心素养四维度目标设计（文化自信 / 语言运用 / 思维能力 / 审美创造）
- 习题按识记→理解→应用→分析→综合→创造六层次分层

## 安装方式

### 方式一：拖入安装（最简单）
下载 `SKILL.md` 文件，直接拖进 WorkBuddy 聊天框即可。

### 方式二：文件夹安装
将整个仓库内容复制到 `~/.workbuddy/skills/chinese-teaching-resources/`。

### 方式三：命令行安装
```bash
npx skills add iithink88/chinese-teaching-resources@chinese-teaching-resources
```

## 技能结构

```
chinese-teaching-resources/
├── SKILL.md                          # AI 执行指令
├── assets/
│   ├── learning-web-template.html    # 交互网页模板（自包含单文件）
│   └── ppt-outline-template.md       # PPT 大纲模板（15 页）
└── references/
    ├── 教案结构规范.md                # 教案撰写规范
    ├── 讲课稿撰写要点.md              # 讲课稿撰写指南
    ├── 习题分层标准.md                # 分层习题命制标准
    └── 小学语文教学大纲要点.md        # 课程标准要点
```

## 使用方法

在 WorkBuddy 中输入：
```
用技能：chinese-teaching-resources，生成《[课文标题]》的教学资源。
```

技能会自动识别年级、单元、核心素养目标，并输出全套 8 件套资源。
